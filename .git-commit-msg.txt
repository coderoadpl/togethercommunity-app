feat: language-aware transactional e-mails

Transactional e-mails are now sent in the recipient's preferred
language (Polish or English), matching the same language logic
already used for the marketing double opt-in flow.

Adds language resolution to the transactional e-mail domain model
and threads it through the relevant use cases, i18n bundles, and
account/settings UI so the sent language stays consistent with the
member's chosen locale.
