# Accessibility checks

`pnpm run a11y` builds the web app, prepares the deterministic development
database, boots the real server, and inspects the public, member, and creator
surfaces with Playwright. It covers all seven themes at desktop width and the
public and member surfaces at mobile width.

The in-house checks report images without `alt`, form controls and interactive
ARIA roles without accessible names, missing or duplicate `main` landmarks,
content outside named landmarks, skipped heading levels, empty table headers,
and text below the WCAG AA contrast minimum. Serious and critical findings fail
the command; moderate and minor findings remain visible in
`out/a11y/a11y-report.json` and `out/a11y/a11y-report.md` without failing it.

## Coverage comparison

The preceding axe-core scan found 61 serious or critical issues in this app:
54 color-contrast failures and seven unnamed progress bars. It also found
missing main and region landmarks, heading-order skips, and empty table headers.
Every one of those categories is covered by the in-house checks, so the
regressions the scan historically caught here still fail the gate.

Contrast is measured from computed styles: the text colour is composited over
the first opaque background in the ancestor chain, and the AA threshold follows
font size and weight. Cases the styles cannot decide are counted and reported
rather than guessed — text over background images or gradients, translucent
elements, text shadows, transparent text fill, clipped or off-screen text (any
ancestor with `clip`/`clip-path` or a box collapsed to 1px — the largest skip
bucket, dominated by screen-reader-only text but not limited to it), native
`option` text, disabled text, and text generated by `::before` or
`::after`. Input and textarea values are measured; placeholders are counted as
skipped because they use a distinct pseudo-element colour. Elements that paint
behind text without being their ancestors are outside the model. These gaps are wider
than axe-core's renderer-aware implementation, so a full contrast audit still
needs a manual pass. The verified run on this revision measured 6,655 of 9,373 text
runs and skipped 2,718 (29.0%); reports expose the current skip count,
percentage, and reasons. The scan asserts per-render floors for both contrast
runs and semantic candidates, so a dead screen fails instead of hiding behind
busier renders.

Breadth is what the swap costs: axe-core shipped roughly ninety rules and these
are the categories this app has ever needed. ARIA attribute validity, nested
interactive controls, table structure, and list semantics are no longer
machine-checked.

`eslint-plugin-jsx-a11y` is removed with it: the plugin itself is MIT, but it
depends on axe-core, so keeping it would keep MPL in the lockfile. The
repository had no outstanding findings from that lint layer before removal. The
runtime checks preserve the categories that produced findings on the rendered
app, but do not claim to reproduce every preventive JSX syntax rule.

The previous post-fix axe-core result had no serious or critical findings. Its
only remaining findings were 14 moderate heading-order skips in creator-authored
lesson HTML, two per theme. The in-house report reproduces exactly those 14
skips and keeps the existing pass/fail threshold.

The first in-house run failed on two real contrast defects, both fixed in the
same change. The banned-member badge was introduced after the last axe-core run
and rendered white on the stock MUI warning fill at 3.11:1 (MUI picks
`contrastText` against a 3:1 floor, so every theme raises `contrastThreshold` to
4.5). The Signal Mono `MuiChip` root override was older: filled primary chips
already painted ink on an ink fill during the previous scan. That scan requested
only axe-core `violations`, so it likely discarded the unresolved contrast result
as `incomplete`. The earlier scoreboard fix addressed the same override pattern
through manual review but did not identify Signal Mono, reinforcing that this
was a coverage/configuration miss rather than a newly introduced defect.
