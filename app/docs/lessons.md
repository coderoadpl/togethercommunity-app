# Reading lesson text

Lesson text uses a reading column up to 44rem wide, centred when the content area is wider. Headings, lists, figures, and tables remain left-aligned inside the column. On phones the text uses the available width.

Long HTML blocks start collapsed so the discussion stays within reach. The visible height is 60% of the viewport, with a minimum of 24rem. A visual fade marks the bottom edge; the complete HTML, including figure captions, stays accessible in one live block clipped to the preview height. Visible text can be selected and copied, links follow their destinations, and images open in a lightbox. Short blocks show all their content without a control.

Choose **Show all** to read a long block in full. **Collapse text** at the bottom returns it to the shorter view. A heading deep link expands its block before scrolling to the heading. Keyboard focus inside the text expands its block, including when Tab reaches a link or an image. Choose **Show all** before using Browser Find to search the full text.

In **Account → Playback**, enable **Expand lesson text automatically** to show long blocks in full when a lesson opens. The setting is off by default and is remembered in this browser. It uses local browser storage, so another browser or device has its own preference, and clearing browser storage resets it.
